Three AI tools I built and released as open source

Each one started as a problem I had myself, and each is public on GitHub with its code, README and licence.

coursera-notes: course material into a study notebook

It turns the Coursera courses you are enrolled in into one editable study notebook: teach-first module pages, a course map, a mind map and question practice.

It runs inside your own AI agent (Claude Code, Codex or Gemini CLI). It builds each page only from the course's own material, so nothing is added from outside. Python.

repo live demo

Chit: voice dictation that stays on your machine

Free, fully local voice dictation for Windows, and a free alternative to cloud dictation tools. Hold Caps Lock, talk, and clean text appears in any app. A small local model removes filler words and applies self-corrections.

It works offline after a one-time model download, in English and Hindi. Python.

repo

ClipNest: a home for the screenshot pile

I save everything useful I find into one unorganised pile. ClipNest is how I am fixing that: a local-first screenshot organiser for Windows.

Snip and add a note. An on-device model reads the screenshot, gives it a title, summary and categories, and turns dates in your note into reminders. No cloud, no account. Rust.
