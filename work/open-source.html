Three open-source AI tools

Each one started as a problem I had myself. Each is public, with its code, README and licence on GitHub.

coursera-notes

Turns the Coursera courses you are enrolled in into one editable study notebook: teach-first module pages, a course map, a mind map and question practice. It runs inside your own AI agent (Claude Code, Codex or Gemini CLI) and builds each page only from the course's own material, so nothing is added from outside. Python.

repo live demo

Chit

Free, fully local voice dictation for Windows. Hold Caps Lock, talk, and clean text appears in any app, with filler words removed and self-corrections applied by a small local model. It works offline after a one-time model download, in English and Hindi. A free alternative to cloud dictation tools. Python.

repo

ClipNest

I save everything useful I find into one unorganised pile. ClipNest is how I am fixing that: a local-first screenshot organiser for Windows. Snip, add a note, and an on-device model reads the screenshot, gives it a title, summary and categories, and turns dates in your note into reminders. No cloud, no account. Rust.
